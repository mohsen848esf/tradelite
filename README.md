# tradelite

A real-time crypto market viewer with candlestick charts and price alerts. Built with React, TypeScript, WebSocket, and lightweight-charts.

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start development server
- `npm run build` — type-check and build for production
- `npm run preview` — preview production build
- `npm run lint` — run ESLint
